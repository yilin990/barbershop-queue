# SOP: 可评论的视觉资产 + 时间线组件

> **奕霖 2026-08-21 拍板**：FreshnessTimeline 这个模式可以复制到其他行业。

## 1. 模式识别（什么时候用这个 SOP）

当业务同时满足以下条件：

- [ ] **商家周期性产生视觉资产**（拍照 / 上传图片）
- [ ] 视觉资产需要**按时间分组**（早/中/晚 / 月 / 周 / 期次）
- [ ] 用户购买或消费前需要**看新鲜度/品质**（决策依据）
- [ ] 需要**用户反馈闭环**（评价/评分/评论）

→ 用 **Timeline + Comment** 组件模式。

## 2. 跨行业应用清单

| 行业 | 周期分组 | 用户决策依据 | 后端表 |
|---|---|---|---|
| **果蔬** (已落地) | 早点 / 中点 / 晚点 | 看 3 天新鲜度 | `PhotoSnapshot` + `SnapshotComment` |
| **餐饮** | 早茶 / 正餐 / 夜宵 | 看菜品实拍 + 评价 | 同上表结构 |
| **美容** | 术前 / 术中 / 术后 | 看效果对比 + 评价 | 同上表结构 |
| **健身** | 每日训练记录 | 看体型变化 + 教练评价 | 同上表结构 |
| **宠物服务** | 寄养前 / 中 / 后 | 看宠物状态 + 主人口碑 | 同上表结构 |
| **4S 店修车** | 接车 / 检测中 / 完工 | 看维修过程 + 车主评价 | 同上表结构 |

**核心抽象**：任何"过程可视化 + 用户反馈"场景都能复用。

## 3. 后端表结构（已落地，跨行业直接复用）

```sql
-- PhotoSnapshot: 商家上传的视觉资产
CREATE TABLE PhotoSnapshot (
  id TEXT PRIMARY KEY,           -- ps_xxx
  productId TEXT,                 -- 或 serviceId / orderId
  merchantId TEXT,
  photoUrl TEXT,                  -- /uploads/snapshots/xxx.jpg
  shotAt TEXT,                    -- ISO 8601
  period TEXT,                    -- 'morning' | 'noon' | 'evening' 或 'pre'|'mid'|'post'
  shotBy TEXT,                    -- 'merchant-staff' / 'system-auto'
  note TEXT                       -- 商家备注
);

-- SnapshotComment: 用户评价
CREATE TABLE SnapshotComment (
  id TEXT PRIMARY KEY,
  snapshotId TEXT,
  productId TEXT,
  userPhone TEXT,
  userNickname TEXT,
  content TEXT,                   -- 评论内容（500 字限）
  rating INTEGER,                 -- 1-5 颗星
  isVerifiedPurchase INTEGER,     -- 已购顾客标记
  createdAt TEXT
);
```

## 4. 前端组件结构（FreshnessTimeline 抽象）

```
<FreshnessTimeline productId={id}>
├── 头部：📷 标题 + "最近 N 天 · 共 X 张"
├── 3 个分组卡（早/中/晚）
│   ├── 卡片背景 = 当天最新照片缩略图
│   ├── 卡片前景 = 分组名 + 总张数
│   └── 点击展开 → 折叠面板
├── 折叠面板（3 天历史）
│   ├── 每天 1 张最新照片（按日期倒序）
│   ├── 大图（72x72，点击放大）
│   ├── 备注折叠（<details> 标签）
│   └── "最新" 徽章（绿色，左上角）
├── 点击图片 → 居中 Modal（max-width 360px）
│   ├── 顶部：时段图标 + 标签 + 时间 + 关闭按钮
│   ├── 照片大图
│   ├── 商家备注卡（折叠备注全文）
│   ├── 评论列表（折叠：默认 2 条 + "查看全部 N 条"）
│   └── "写评价" 按钮（需要登录）
│       └── 未登录 → 登录选项对话框（取消 / 去登录）
└── 登录对话框
    ├── 锁图标 + "登录后才能评价" 提示
    ├── 取消按钮
    └── 去登录按钮（跳 /me 登录页）
```
