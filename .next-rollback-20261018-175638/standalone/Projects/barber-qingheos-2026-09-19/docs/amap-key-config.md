## 三、配置域名白名单（重要！）

### 为什么需要白名单？
高德 Web JS API 2.0 默认只允许在**已配置域名**下调用。
未配置时手机浏览器访问会直接**黑屏/白屏**。

### 需要添加的域名

| 环境 | 域名 | 说明 |
|------|------|------|
| 开发 | `localhost` | PC 本地开发 |
| 开发 | `127.0.0.1` | PC 本地开发备选 |
| 内网 | `192.168.0.103` |奕霖的 Mac局域网 IP |
| 生产 | `*.yourdomain.com` | 上线后替换为实际域名 |

### iOS Safari额外配置

如果 App 可能在 iOS Safari 或微信内嵌浏览器（WKWebView）访问，需要额外添加：

| 环境 | 域名 | 说明 |
|------|------|------|
| iOS 测试 | `*` | 通配符，仅测试用，生产环境禁止 |
| iOS 生产 | `你的实际域名` | 必须填写真实域名 |

>⚠️ 生产环境**不要用 `*`**，会被高德拒绝。

### Android Chrome

Android Chrome 通常**不强制检查域名白名单**（比 iOS 宽松）。
但如果 App 打了 APK 或在 WebView 里，建议也加上对应域名。

## 六、常见问题

### Q：手机端地图黑屏
**A：** 最常见原因是域名白名单没有 `192.168.0.103`。立即去加。

### Q：PC 能开，手机不能开
**A：** iOS Safari 有跨域限制，必须把 `192.168.0.103` 加入白名单。

### Q：加了白名单还是不行
**A：** 
1. 确认 Key状态是「启用」
2. 确认「Web端 JS API」已勾选
3. 等待 5 分钟（高德配置有缓存）
4. 清除浏览器缓存重试

### Q：微信里打不开
**A：** 微信使用自己的 WebView，需要在白名单里加上微信 H5 域名（通常需要 ICP备案域名）。内网 IP 无法在微信内使用地图。
