## 二、模块1：个人账号系统

### 2.1 功能清单

#### 2.1.1 登录注册

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 手机号+验证码登录 | 国内最常用，1分钟完成注册 | P0 |
| 微信一键登录 | 扫码即登录，体验最优 | P1（后期） |
| 邮箱登录 | 备用方案 | P2（后期） |

**登录流程（手机号验证码）**：

```
用户输入手机号
    ↓
点击"获取验证码" → 60秒倒计时
    ↓
输入6位验证码
    ↓
点击"登录/注册" → 后端验证
    ↓
验证成功 → 创建/更新用户记录 → 返回JWT Token
    ↓
前端存储Token到localStorage → 跳转用户中心
```

#### 2.1.2 用户资料

| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | string | 自动生成UUID |
| 手机号 | string | 唯一，用于登录 |
| 昵称 | string | 默认"芝林用户+随机数字"，可修改 |
| 头像 | string | 默认随机头像，后续可上传 |
| 会员等级 | enum | 普通/银卡/金卡/VIP |
| 注册时间 | datetime | 自动记录 |
| 最后登录 | datetime | 自动更新 |

#### 2.1.3 会员等级体系

参考芝林药房实体业务，设计虚拟会员等级（不影响实体消费）：

| 等级 | 获取条件 | 权益 |
|------|----------|------|
| 普通 | 注册即得 | 基础评论、反馈 |
| 银卡 | 累计评论3次 | 解锁"客户故事"发表 |
| 金卡 | 累计评论10次+被点赞20次 | 解锁专属标识 |
| VIP | 管理员人工授予 | 解锁全部功能、优先客服 |
